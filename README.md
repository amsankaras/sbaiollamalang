# Spring Boot AI LangChain4j Langraph4j

This is a Spring Boot application that integrates AI capabilities using LangChain4j, Langraph4j, and supports local Ollama Llama 3.1.

## Features
- **Spring Boot**: Backend framework for building Java applications.
- **LangChain4j**: Library for building AI-driven workflows.
- **Langraph4j**: Graph-based AI processing.
- **Ollama Llama 3.1**: Local AI model integration.

## Requirements
- Java 17 or higher
- Maven

## Getting Started
1. Clone the repository.
2. Navigate to the project directory.
3. Run the application:
   ```bash
   mvn spring-boot:run
   ```

## Configuration
- Modify `application.properties` for custom configurations.

## Dependencies
- Spring Boot Starter
- LangChain4j
- Langraph4j
- Ollama Llama 3.1
